# TUK Data Merge Tool

Merges the 4 Excel files exported from TUK (Dubai + Abu Dhabi, building list + point list) into 3 files: Project List, Point List and Sales List.

All processing runs in the browser. Files are never uploaded.

## Files
- `index.html` – the tool (single page)
- `logo.png` – horizontal logo shown in the page header
- `logo-Profile.png` – square icon used as favicon / apple-touch-icon

Filenames are case-sensitive.
